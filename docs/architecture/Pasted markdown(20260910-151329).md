## 7. Failure Recovery Guide (Demo Safety Net)

| Failure Scenario | Root Cause | Instant Recovery Action |
|---|---|---|
| Frontend fails to connect to backend | Backend window closed or port 8000 blocked | Re-run `start.bat` or manually execute `cd backend && .venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000`. |
| Storm injection does not update map | WebSocket connection dropped | Refresh browser page (`F5`). WebSocket auto-reconnects and requests fresh `SNAPSHOT` frame (`ws.py#L15`). |
| Photo upload fails in Field Report | File extension or size invalid | Select a standard `.jpg` or `.png` image under 5MB. |
| Python missing dependencies | `.venv` incomplete | Run `simulate.bat` or execute `.venv\Scripts\pip install -r backend/requirements.txt`. |
| Port 5173 or 8000 in use | Previous process hanging | Open Task Manager and terminate `python.exe` and `node.exe` processes, then double-click `start.bat`. |
